# ADK-Multi-Agent-Systems-Portfolio

This repository contains five **end-to-end AI agents** built using Google’s **Agent Development Kit (ADK)**, showcasing research, automation, and production-quality assistant capabilities.  
Each agent includes source code, execution guides, and demo videos.

---

## Overview

**(a) Deep Research Lead Generation Agent** 
- Performs deep research to discover and enrich qualified B2B leads based on user-defined criteria. 
- ADK, web-scraping tools, entity extraction, data enrichment

  [Video ▶](#videos)


**(b) Advanced Tool Agent using Gemini CLI** 
- Integrates the Gemini CLI as a tool in an ADK pipeline, demonstrating multi-tool orchestration.
- ADK, Gemini CLI, Python subprocess

  [Video ▶](#videos)


**(c) MCP Tools–Based Bug Assistance Agent** 
- Debugging assistant using Model Context Protocol (MCP) tools to locate and propose fixes in codebases.
- ADK, MCP tools, repo analysis

  [Video ▶](#videos)


**(d) Production Code Review Assistant** 
- Production-grade code review assistant for CI/CD with contextual analysis and risk scoring.
- ADK, GitHub Actions, LLM reasoning

  [Video ▶](#videos)


**(e) Production E-Commerce Agent** 
- A retail assistant built with ADK, MCP, and AlloyDB that manages search, recommendations, and checkout flows.
- ADK, AlloyDB, SQL, MCP

  [Video ▶](#videos)
